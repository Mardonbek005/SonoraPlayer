# 🎵 Sonora Player

**Sonora Player** — Android 14–16 qurilmalari uchun mo'ljallangan, zamonaviy dizaynga ega professional va yuqori sifatli musiqa pleyeri.

## ✨ Asosiy Xususiyatlar
- 🌟 **Premium UI/UX:** Material Design 3, Glassmorphism, Neumorphism va Dynamic Color.
- 🎧 **Audio Sifat:** Media3 (ExoPlayer) asosida Gapless Playback, Crossfade, Equalizer va Bass Boost.
- 📱 **Moslashuvchanlik:** Katta kutubxonalar (100k+ qo'shiq) uchun optimallashtirilgan.
- 🔒 **Developer Mode:** Maxsus yashirin test va xatoliklarni kuzatish paneli.
- 💳 **Pro Versiya:** Google Play Billing Library orqali xavfsiz xarid tizimi.

## 🛠 Texnologiyalar
- Kotlin, Jetpack Compose, Material 3
- Media3 ExoPlayer, Room Database, DataStore
- Hilt Dependency Injection, Coroutines & Flow
- WorkManager, Coil, Palette API
